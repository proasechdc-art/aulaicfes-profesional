# AulaICFES Profesional

Aplicación web estática para gestión académica, banco de preguntas, simulacros, impresión de pruebas y horarios.

## Estado

Paquete fuente recibido el 4 de noviembre de 2026. La integración de Supabase y las políticas de acceso se encuentran en preparación y deben validarse antes de habilitar uso real con estudiantes.

## Despliegue

Sitio estático HTML/CSS/JavaScript. Punto de entrada: `index.html`.
